mlx_cluster.random_walk(rowptr: mlx.core.array, col: mlx.core.array, start: mlx.core.array, rand: mlx.core.array, walk_length: int, *, stream: object | None = None) → tuple#

Uniform random walks.

Parameters:

  • rowptr (mlx.core.array) -- rowptr of graph in csr format.

  • col (mlx.core.array) -- edges(col) in csr format.

  • start_indices (mlx.core.array) -- starting nodes of graph from which sampling will be performed.

  • random_values (mlx.core.array) -- random values (between 0 to 1)

  • walk_length (int) -- walk length of random graph

Returns:

mlx_cluster.rejection_sampling(rowptr: mlx.core.array, col: mlx.core.array, start: mlx.core.array, walk_length: int, p: float, q: float, *, stream: object | None = None) → tuple#

Sample nodes from the graph by sampling neighbors based on probablity p and q

Parameters:

  • rowptr (mlx.core.array) -- rowptr of graph in csr format.

  • col (mlx.core.array) -- edges in csr format.

  • start (mlx.core.array) -- starting node of graph from which biased sampling will be performed.

  • walk_length (int) -- walk length of random graph

  • p (float) -- Likelihood of immediately revisiting a node in the walk.

  • q (float) -- Control parameter to interpolate between breadth-first strategy and depth-first strategy

Returns:

tuple (mlx.core.array, mlx.core.array)

Heterogeneous graphs#

mlx_cluster.hetero_neighbor_sample(colptr_dict: Mapping[Tuple[str, str, str], array], row_dict: Mapping[Tuple[str, str, str], array], seed_dict: Mapping[str, array], num_neighbors: Sequence[int] | Mapping[Tuple[str, str, str], Sequence[int]], num_nodes_dict: Mapping[str, int] | None = None, replace: bool = False, directed: bool = True, seed: int | None = None) → HeteroSamplerOutput[source]#

Multi-hop neighbor sampling on a heterogeneous graph (GraphSAGE style).

For every edge type (src, rel, dst) and every hop, up to k incoming src neighbors are sampled for each dst node discovered at the previous hop (the seeds at hop 0).

Parameters:

  • colptr_dict (Mapping[Tuple[str, str, str], array]) -- CSC column pointers per edge type. For (src, rel, dst) this has num_dst_nodes + 1 int64 entries.

  • row_dict (Mapping[Tuple[str, str, str], array]) -- CSC row indices (source node of each edge, sorted by destination) per edge type, int64.

  • seed_dict (Mapping[str, array]) -- Seed node ids per node type. Must not contain duplicates.

  • num_neighbors (Union[Sequence[int], Mapping[Tuple[str, str, str], Sequence[int]]]) -- Fan-out per hop, e.g. [10, 5]. Either a single list used for every edge type, or a dict mapping each edge type to its own list. -1 takes all neighbors; 0 samples none. Shorter lists are padded with 0.

  • num_nodes_dict (Optional[Mapping[str, int]]) -- Optional number of nodes per node type (e.g. HeteroGraphData.num_nodes). Lets node types that only appear as a source use the faster dense id mapper.

  • replace (bool) -- Sample with replacement.

  • directed (bool) -- Only True is supported for heterogeneous graphs.

  • seed (Optional[int]) -- Seed for the sampler's RNG. If None, one is drawn from MLX's global RNG, so mx.random.seed(...) makes sampling reproducible.

Return type:

HeteroSamplerOutput

Returns:

HeteroSamplerOutput

Example:

out = hetero_neighbor_sample(
    colptr_dict={("author", "writes", "paper"): colptr},
    row_dict={("author", "writes", "paper"): row},
    seed_dict={"paper": mx.array([0, 1], dtype=mx.int64)},
    num_neighbors=[10, 5],
)
out.node_id["author"]                         # sampled author ids
et = ("author", "writes", "paper")
edge_index = mx.stack([out.row[et], out.col[et]])
