mlx-cluster documentation
=========================

Welcome to the mlx-cluster documentation!

This documentation covers the two core Python API functions exposed by the package:

- `random_walk`: Performs uniform random walks on graphs.
- `rejection_sampling`: Performs biased sampling on graphs using rejection sampling based on parameters p and q.
